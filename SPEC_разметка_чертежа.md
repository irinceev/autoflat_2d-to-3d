# Спецификация: цветной чертёж → 3D-модель

## 1. Формат файла
- **PNG**, RGB, без альфа-канала.
- Линии — **сплошной заливкой одного цвета**, без градиентов/полупрозрачности. Сглаживание (antialiasing) не критично — парсер классифицирует пиксели по ближайшему цвету из палитры с допуском, но чем меньше сглаживания, тем чище результат.
- Толщина линии стены: **минимум 10-15 px** при итоговом экспорте (чтобы после калибровки толщина в метрах была вменяемой и не терялась при обработке). Толщину стены на картинке рисуй **пропорционально реальной** (наружная стена визуально толще внутренней перегородки) — реальная толщина потом считается из самой геометрии рисунка, а не из констант.
- Размер холста: любой, но чем выше разрешение, тем точнее калибровка. Рекомендую **2000+ px по большей стороне**.
- Фон — **белый** (255,255,255). Всё не закрашенное спецкраской = пол/площадь комнаты.

## 2. Палитра

| Элемент | Цвет | HEX | RGB |
|---|---|---|---|
| Наружная стена | красный | `#FF0000` | 255,0,0 |
| Внутренняя перегородка | синий | `#0000FF` | 0,0,255 |
| Дверной проём | зелёный | `#00FF00` | 0,255,0 |
| Оконный проём (обычное) | жёлтый | `#FFFF00` | 255,255,0 |
| Оконный проём (маленькое, санузел) | оранжевый | `#FFA500` | 255,165,0 |
| Калибровочный отрезок | пурпурный | `#FF00FF` | 255,0,255 |
| Метка/номер комнаты | чёрный | `#000000` | 0,0,0 |
| Граница зоны учёта (без стены — открытая планировка) | голубой/циан | `#00FFFF` | 0,255,255 |
| Фон / пол | белый | `#FFFFFF` | 255,255,255 |

### 2.1 Мебель — цвет прямоугольника = тип
Каждый предмет мебели — залитый прямоугольник в реальном масштабе (габарит = как нарисуешь, с учётом калибровочного отрезка) одним из следующих цветов — **цвет сам говорит парсеру, что это за предмет**, никакой CSV с типом заполнять не нужно:

| Тип | HEX | Высота по умолчанию |
|---|---|---|
| Кровать (bed) | `#CD853F` | 0.55 м |
| Диван (sofa) | `#4682B4` | 0.80 м |
| Шкаф (wardrobe) | `#8B4513` | 2.10 м |
| Кухня (kitchen) | `#2E8B57` | 0.90 м |
| Стол (table) | `#800080` | 0.75 м |
| Стул (chair) | `#DB7093` | 0.90 м |
| Тумба (nightstand) | `#006400` | 0.50 м |
| Унитаз (toilet) | `#B0E0E6` | 0.40 м |
| Раковина (sink) | `#191970` | 0.85 м |
| Ванна (bathtub) | `#F0E68C` | 0.50 м |

Мебель не мешает разделению комнат (не барьер) и не становится стеной в 3D — просто коробка нужной высоты на полу, того же цвета в `.obj`/`.mtl` (видно в Blender).

Комната, к которой относится предмет, определяется автоматически (по тому, в какой комнате лежит прямоугольник). После первого прогона парсер создаст `furniture_overrides_template.csv` — он **не обязателен**, нужен только если хочешь переопределить высоту конкретного предмета (например, у тебя нестандартный шкаф).

**Автоматическая проверка:** если нарисованный прямоугольник перекрывает дверной проём — парсер выдаст предупреждение в консоли и подсветит подпись предмета красным на `debug_rooms.png`. Просто подвинь прямоугольник на чертеже и прогони заново.

### 2.1 Когда нужен голубой (циан)
Если между двумя помещениями **физически нет стены** (открытая планировка — например, прихожая переходит в кухню-гостиную без перегородки), но их всё равно нужно считать как отдельные позиции в смете — раздели их тонкой **голубой** линией вместо красной/синей. Парсер разделит их на разные комнаты для расчёта площадей, но **не** построит по этой линии стену в 3D-модели (в отличие от красной/синей).

## 3. Как рисовать проёмы (важно!)
Дверь/окно — это **не дополнительная линия поверх стены**, а **замена цвета стены на этом участке**. То есть там, где в реальности дверь — красная/синяя линия стены **прерывается и перекрашивается** в зелёный (дверь) или жёлтый/оранжевый (окно) на всю ширину проёма. Так парсер понимает: здесь стена физически отсутствует (проём), но граница между помещениями всё равно есть (для правильного разделения комнат).

## 4. Калибровка масштаба
Нарисуй в любом свободном месте холста (за пределами квартиры) **один отрезок пурпурного цвета** (`#FF00FF`), прямой (горизонтальный или вертикальный), **длина которого в реальности равна ровно 1.000 м** в том же масштабе, что и вся остальная квартира. Масштаб самого чертежа может быть любым — главное, что этот отрезок и все стены нарисованы в одном и том же масштабе.

## 5. Разметка помещений
В каждой комнате поставь **одну чёрную точку** (кружок диаметром 15-30 px) примерно в центре комнаты. Цифры/буквы рядом писать не обязательно — номер комнате присвоит парсер автоматически (по порядку слева-направо, сверху-вниз) и покажет тебе **отладочную картинку** с номерами поверх твоего чертежа. Дальше просто сверяешь номера с реальными названиями и вписываешь в CSV-шаблон (сгенерируется автоматически):

```csv
room_id,name,height_m,flooring
1,Прихожая,2.47,Плитка керамическая
2,Кухня-Гостиная,2.89,Ламинат
...
```

Если название не указать — комната останется как "Комната №N" с высотой по умолчанию.

## 6. Высота стен
По умолчанию все стены поднимаются на **единую хардкод-высоту** (константа `DEFAULT_WALL_HEIGHT_M = 2.7` в коде парсера — правишь одну строку под свой случай). Если хочешь разную высоту по комнатам — заполни колонку `height_m` в CSV-шаблоне, тогда для каждой комнаты возьмётся её значение (стены на границе высокой и низкой комнаты просто получат бОльшую из двух высот).
