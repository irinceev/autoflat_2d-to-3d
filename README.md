# Планировка → 3D-модель → мебель → смета

Пайплайн, который превращает цветной PNG-чертёж квартиры в упрощённую 3D-модель
(`.obj` + `.mtl`) и Excel-таблицу объёмов строительных работ. Сделано как
тестовое задание по автоматизации сметного дела: `2D-планировка → 3D-модель →
расстановка мебели → расчёт объёмов → смета`.

## Идея

Вместо того чтобы сразу распознавать произвольный архитектурный PDF, процесс разбит на два этапа:

1. **Человек упрощает чертёж** — обводит план в цветной PNG по фиксированной
   палитре - трассировка контуров поверх исходного плана.
2. **Код делает всё остальное автоматически** — разделение на комнаты
   (заливка связных областей), разбиение произвольной формы на прямоугольники
   (работает и на Г-образных помещениях), расчёт площадей/периметров/проёмов,
   генерация 3D-модели с материалами, экспорт в Excel.

## Установка

```bash
pip install numpy opencv-python scipy pillow openpyxl matplotlib
```

## Как пользоваться

Полные правила разметки чертежа (цвета, калибровка, требования к PNG) — в
[`SPEC_разметка_чертежа.md`](./SPEC_разметка_чертежа.md). Коротко:

### 1. Нарисовать чертёж
Цветной PNG: красный контур — наружные стены, синий — перегородки, зелёный /
жёлтый / оранжевый — двери / окна, пурпурный отрезок ровно 1 м — калибровка
масштаба, чёрные точки — по одной в каждой комнате, цветные прямоугольники —
мебель (цвет = тип, см. таблицу в SPEC).

### 2. Первый прогон — найти комнаты и мебель
```bash
python parse_floorplan_image.py plan.png
```
Создаёт:
- `debug_rooms.png` — план с номерами комнат и подписями мебели (перекрытие
  дверного проёма подсвечивается красным)
- `rooms_legend_template.csv` — пустой шаблон, нужно заполнить
- `furniture_overrides_template.csv` — необязательный override высоты мебели

### 3. Заполнить легенду комнат
```csv
room_id,name,height_m,flooring
1,Прихожая,2.47,Плитка керамическая
2,Кухня-Гостиная,2.89,Ламинат
```

### 4. Финальная сборка
```bash
python build_from_parsed.py plan.png --legend rooms_legend.csv
```
Создаёт:
- `apartment_model_scanned.obj` + `.mtl` — 3D-модель с материалами
  (стены/пол/потолок/мебель разного цвета)
- `smeta_scanned.xlsx` — площадь пола/стен(нетто)/потолка, периметр, двери,
  окна, длина плинтуса, тип покрытия — по каждой комнате, плюс отдельный
  лист «Мебель»
- `floorplan_2d_scanned.png` — план сверху для визуальной проверки

### 5. Открыть в Blender
`File → Import → Wavefront (.obj)`, включить **Split By → Group**. Материалы
подхватятся автоматически из `.mtl`, лежащего рядом.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `parse_floorplan_image.py` | Разбор PNG: калибровка масштаба, поиск комнат/дверей/окон/мебели |
| `build_from_parsed.py` | Сборка `.obj`/`.mtl`/Excel/визуализации по результатам разбора + легенде |
| `geometry_engine.py` | Низкоуровневый движок мешей (боксы, материалы, запись OBJ/MTL) |
| `furniture.py` | Палитра типов мебели (цвет ↔ тип ↔ высота по умолчанию) |
| `blender_setup.py` | Автоимпорт модели в Blender с очисткой сцены |
| `SPEC_разметка_чертежа.md` | Полные правила разметки чертежа |

## Что автоматизировано, а что нет

Вручную: трассировка исходного плана в цветной PNG, расстановка мебели
(тип и положение — творческое решение человека), заполнение названий/высот
комнат в CSV-легенде.

Автоматически: поиск комнат и их геометрии, разбиение произвольной формы на
прямоугольники, расчёт всех площадей/периметров/проёмов, привязка мебели к
комнате и проверка на перекрытие дверей, генерация 3D-модели и Excel.
